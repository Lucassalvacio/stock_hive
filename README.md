# stock_hive

**Stock Hive** is a business management app built with **Flutter** and **Firebase**, designed to help small to medium enterprises streamline inventory, vendor, and financial operations — all in one place.

---

## 🚀 Features

- 🔐 **User Authentication**
  - Secure login using Firebase Authentication
  - Role-based access control for **Admin** and **User**

- 📦 **Product & Vendor Management**
  - Add, edit, delete, and view product lists
  - Manage vendors with company-specific pricing
  - Real-time updates powered by **Cloud Firestore**

- 🧾 **Order Tracking**
  - Fetch and track orders via integrated **REST API**
  - Keep all transaction data synchronized across devices

- ⏰ **Smart Reminders & Notifications**
  - Receive notifications for low stock, due payments, or deadlines

- 📊 **Analytics Dashboard**
  - Visualize company data: sales trends, top vendors, and stock performance
  - Filter results per company for multi-tenant setups

- 💰 **Finance Overview**
  - Track total balance, spending, and transaction history
  - Insights for budgeting and business performance

---

## 🏗️ Tech Stack

| Layer | Technology |
|-------|-------------|
| Frontend | Flutter (Dart) |
